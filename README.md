# FitZone Gym & Fitness

A responsive, build-free static website based on the supplied FitZone page references.

## Pages

- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `plans.html` — Membership plans
- `trainers.html` — Trainers
- `gallery.html` — Filterable gallery
- `contact.html` — Contact form and FAQ

## Run locally

Open `index.html` directly, or serve the folder with any static server.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload everything in this folder to the repository root.
3. Open **Settings → Pages** in GitHub.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The contact and newsletter forms are demo-only. Connect them to Formspree, Netlify Forms, EmailJS, or your own backend for live submissions.

## Customize

- Global colors and layout: `assets/css/style.css`
- Shared navigation, footer, filters, FAQ, and demo forms: `assets/js/site.js`
- Photos: `assets/images/`
